# tiktok短视频复刻需求-001

在项目中进行二次开发，增加tiktok短视频复刻工作流

### 整体工作流

首版设计如下：

1. 对视频进行片段切分和关键帧提取
2. 针对关键帧进行新场景替换
3. 针对新场景关键帧进行人物替换
4. 对每个片段，使用 视频片段 + 新关键帧 生成新视频片段
5. 组装各视频片段，附上源音频，形成新视频

本需求先完成第一阶段（视频进行片段切分和关键帧提取）

### 1. 使用 scenedetect 进行片段切割

1. 阈值先设定为50

scenedetect -b pyav -i source_video.mp4 -o res_dir detect-content  --threshold 50  --min-scene-len 12  list-scenes split-video

2. 切割完后， >=15s 的片段需进一步分割

继续使用 scenedetect，但将阈值进一步降低(每次降低5)


### 2. 关键帧提取

获取每个切割片段的首帧（往后选尽可能清晰）作为关键帧


### 3. 片段重组

写一个片段重组的算法，要求：
1. 两个3.2s以上的片段不主动合并
2. 最多3个片段合并到一起
3. 合并后的片段必须不少3.2s
4. 合并后的片段必须不高于15s
5. 合并时，尽可能选择场景相似的片段合并
6. 如果合并不上，可丢弃小于1s的片段
